pyplotdesigner
==============

Design Matplotlib figure layouts visually, then reuse them in Python. Position and size axes in the browser, connect them with constraints, and use named constants to control spacing and dimensions in your plotting script.

Start with :doc:`getting-started`, or copy and run the :doc:`two-panel example <worked-example>`.
